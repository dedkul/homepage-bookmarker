Homepage: layout explorations v0.1

Four directions for the same v1 content: clock, world clocks, search, favorites (1 or 2 rows), tasks and notes. Open the slider button (bottom-right) on any page to change rows, items per row, background, theme and link behaviour.

A · Focus

Firefox-style centred stack. Tasks and notes hide in a drawer. Quietest option and closest to a default new tab.

 B · Dock

Search in the centre, favorites in a macOS-style dock, clocks and tasks around the edges.

 C · Editorial

Split layout led by typography. Large serif time and a world-clock list on the left, tools on the right.

 D · Bento

A grid of widget cards. Most expandable for v2 widgets; also the busiest.
